# 喵喵记账本 - AccountBook

一个功能完善的Android记账本应用，使用Jetpack Compose和Room数据库开发，帮助用户轻松管理个人财务。

## 功能特点

### 🏠 首页
- **收支概览**：直观显示当月总收入、总支出和结余
- **交易记录**：按时间顺序展示所有收支记录
- **月份筛选**：支持查看不同月份的财务数据
- **快速添加**：悬浮按钮快速添加新的收支记录

### 💰 记录管理
- **添加记录**：支持添加收入和支出记录
- **编辑记录**：随时修改已有的记录
- **删除记录**：删除不需要的记录
- **分类选择**：为每笔记录选择对应的收支分类
- **日期时间**：记录交易发生的具体日期和时间
- **备注信息**：添加备注说明，方便记忆

### 📊 统计分析
- **月度统计**：显示当月总收入、支出和结余
- **分类统计**：按分类展示支出占比（饼图）
- **趋势图表**：每日收支趋势线图
- **月度对比**：各月份收支对比（柱状图）
- **年度统计**：年度收支汇总（柱状图）
- **分类详情**：点击查看某分类下的所有记录

### 📁 分类管理
- **默认分类**：内置常用收支分类
- **自定义分类**：添加、修改、删除分类
- **分类类型**：支持收入和支出两种类型
- **颜色标识**：为不同分类设置不同颜色

### 🎯 预算管理
- **预算设置**：设置月度预算金额
- **预算提醒**：启用/禁用预算提醒功能
- **预算跟踪**：实时显示预算使用情况

### ⚙️ 数据管理
- **数据导出**：将所有记录导出为CSV文件
- **数据导入**：从CSV文件导入记账数据
- **文件分享**：分享导出的CSV文件
- **数据备份**：通过导出功能备份数据

## 技术栈

- **UI框架**：Jetpack Compose
- **数据库**：Room Database
- **架构组件**：ViewModel、LiveData
- **图表库**：MPAndroidChart
- **编程语言**：Kotlin
- **构建工具**：Gradle

## 安装说明

1. 克隆项目到本地
2. 使用Android Studio打开项目
3. 等待Gradle同步完成
4. 连接Android设备或启动模拟器
5. 点击运行按钮安装应用

## 使用说明

### 添加记账记录
1. 点击首页右下角的"+"按钮
2. 选择收入或支出类型
3. 输入金额
4. 选择分类
5. 选择日期和时间
6. 添加备注（可选）
7. 点击"保存"按钮

### 查看统计数据
1. 点击底部导航栏的"统计"
2. 查看各类统计图表
3. 使用年月选择器切换不同时间段
4. 点击饼图查看分类详情

### 管理分类
1. 点击首页顶部的分类管理按钮
2. 查看现有分类列表
3. 点击"+"添加新分类
4. 点击分类可编辑或删除

### 设置预算
1. 进入设置页面
2. 点击"预算设置"
3. 启用预算提醒
4. 输入月度预算金额
5. 保存设置

### 数据导入导出
1. 进入设置页面
2. 点击"导出数据"生成CSV文件
3. 点击"导入数据"选择CSV文件导入
4. 选择分享方式分享导出的文件
